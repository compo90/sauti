# Sauti — démo en ligne

Ligne vocale de santé maternelle en langues nationales du Sénégal (équipe Echo Sahel,
Kiriku Voice Inclusive & Creative Challenge 2026). Parlez en wolof : M-Kiriku-ASR
transcrit, Sauti détecte d'abord les signes de danger obstétrical, puis répond avec
Kiriku-TTS. Un filet de sécurité oui/non rattrape les erreurs de l'ASR.

Code : https://github.com/compo90/sauti · Vidéo : https://youtu.be/SiCGVt_BgjM

⚠️ Prototype de recherche : contenu médical en attente de validation clinique.
